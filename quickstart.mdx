This guide walks you through running HelpDesk Pro 2026 on your local machine. You will need the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0), a free [Supabase](https://supabase.com) account, and either Visual Studio 2022+ or VS Code with the C# Dev Kit extension.

<Warning>
  **Never commit real Supabase credentials to source control.** The `SupabClient.cs` file currently contains a hardcoded URL and anon key (see Step 4). Before pushing to any public or shared repository, move those values into `appsettings.Development.json` and ensure that file is listed in `.gitignore`.
</Warning>

<Steps>
  <Step title="Clone the repository">
    Open a terminal and clone the project from GitHub:

    ```bash
    git clone https://github.com/Juan-VM/HelpDesk_Pro_2026.git
    cd HelpDesk_Pro_2026
    ```
  </Step>

  <Step title="Open the solution">
    Open the solution file in your preferred editor:

    ```bash
    # Visual Studio — double-click, or:
    start HelpDesk_Pro_2026.sln

    # VS Code
    code HelpDesk_Pro_2026/
    ```

    The project targets **net10.0** (`HelpDesk_Pro_2026.csproj`) and uses implicit usings and nullable reference types.
  </Step>

  <Step title="Create a Supabase project">
    1. Go to [supabase.com](https://supabase.com) and create a new project.
    2. Once the project is provisioned, navigate to **Settings → API**.
    3. Copy the two values you will need:
       - **Project URL** — e.g. `https://xxxxxxxxxxxxxxxxxxxx.supabase.co`
       - **anon / public key** — the `anon` key listed under *Project API keys*

    <Tip>
      You will also need the **Database connection string** from **Settings → Database → Connection string → .NET (Npgsql)**. It looks like `Host=db.xxxx.supabase.co;Database=postgres;Username=postgres;Password=your-password`.
    </Tip>
  </Step>

  <Step title="Configure credentials in appsettings.Development.json">
    Create (or update) `HelpDesk_Pro_2026/appsettings.Development.json` with your Supabase project values. This file is loaded automatically when `ASPNETCORE_ENVIRONMENT=Development` (set by default in `launchSettings.json`).

    ```json
    {
      "Supabase": {
        "Url": "https://YOUR_PROJECT_ID.supabase.co",
        "Key": "YOUR_SUPABASE_ANON_KEY"
      },
      "ConnectionStrings": {
        "DefaultConnection": "Host=db.YOUR_PROJECT_ID.supabase.co;Database=postgres;Username=postgres;Password=YOUR_DB_PASSWORD;SSL Mode=Require;Trust Server Certificate=true"
      }
    }
    ```

    The `DefaultConnection` string is consumed by `AppDbContext` (EF Core) for analytics queries:

    ```csharp
    builder.Services.AddDbContext<AppDbContext>(options =>
        options.UseNpgsql(builder.Configuration.GetConnectionString("DefaultConnection")));
    ```

    **Move hardcoded credentials out of `SupabClient.cs`.**  
    The current `SupabClient.cs` reads URL and key as string literals. Replace them with configuration injection:

    ```csharp
    // Services/SupabClient.cs — updated version
    public static class SupabClient
    {
        private static Supabase.Client? _client;

        public static async Task<Supabase.Client> GetClient(IConfiguration config)
        {
            if (_client == null)
            {
                var url = config["Supabase:Url"]!;
                var key = config["Supabase:Key"]!;
                _client = new Supabase.Client(url, key);
                await _client.InitializeAsync();
            }
            return _client;
        }
    }
    ```

    Then update the singleton registration in `Program.cs`:

    ```csharp
    builder.Services.AddSingleton<Supabase.Client>(serviceProvider =>
    {
        var config = serviceProvider.GetRequiredService<IConfiguration>();
        return SupabClient.GetClient(config).GetAwaiter().GetResult();
    });
    ```

    <Warning>
      Add `appsettings.Development.json` to your `.gitignore` if it is not already present. The production `appsettings.json` in source control should contain only placeholder values or be omitted entirely.
    </Warning>
  </Step>

  <Step title="Run the application">
    Restore packages and start the development server:

    ```bash
    cd HelpDesk_Pro_2026
    dotnet run
    ```

    The app starts on `http://localhost:5173` (HTTP) and `https://localhost:7066` (HTTPS) as defined in `Properties/launchSettings.json`. Your browser should open automatically.

    <Info>
      On first run, `AppDbContext` connects to your Supabase PostgreSQL database. Make sure the `tickets` and `priorities` tables exist in Supabase before navigating to the analytics dashboard.
    </Info>
  </Step>

  <Step title="Register the first account">
    Navigate to `/Account/Register` and complete the registration form. Provide:
    - Full name
    - Email address
    - Password

    The new account is created in Supabase Auth and a corresponding profile record is inserted into the `usuarios` table. The default role assigned is **EMPLEADO**.
  </Step>

  <Step title="Assign the SUPERUSUARIO role">
    Because the first account starts as EMPLEADO, you need to bootstrap a super admin. You have two options:

    <Tabs>
      <Tab title="Via Supabase Dashboard (Bootstrap)">
        Open your Supabase project, go to **Table Editor → usuarios**, find the row for your account, and set the `role` column to `SUPERUSUARIO`. Save the row.

        ```sql
        -- Or run this in the Supabase SQL Editor:
        UPDATE usuarios
        SET role = 'SUPERUSUARIO'
        WHERE email = 'your-email@example.com';
        ```
      </Tab>
      <Tab title="Via Admin Panel (Subsequent Users)">
        Once at least one SUPERUSUARIO exists, log in with that account and navigate to **Admin → Manage Users**. From the `AdminUsersController`-powered panel, click **Change Role** next to any user to promote or demote them without touching the database.
      </Tab>
    </Tabs>
  </Step>
</Steps>
