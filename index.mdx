HelpDesk Pro 2026 is an IT support ticketing platform that connects employees who need technical help with support technicians who resolve issues. Built on ASP.NET Core MVC (.NET 10) with Supabase as the backend, it provides a complete workflow from ticket creation through resolution — with role-based visibility, automated assignment, file attachments, and a real-time analytics dashboard.

## What's Inside

HelpDesk Pro 2026 ships with everything needed to run a fully functional IT help desk:

<CardGroup cols={3}>
  <Card title="Ticket Management" icon="list-check">
    Create, edit, and track support tickets with subject, description, priority, risk, category, and system fields.
  </Card>
  <Card title="State Workflow" icon="diagram-project">
    A strict five-state machine (PENDIENTE → EN PROCESO → EN REVISIÓN → RESUELTO / CANCELADO) keeps tickets on track.
  </Card>
  <Card title="Auto-Assignment" icon="user-check">
    New tickets are automatically assigned to the least-busy support technician to balance workload.
  </Card>
  <Card title="File Attachments" icon="paperclip">
    Attach multiple files per ticket, stored in Supabase Storage and linked to the ticket record.
  </Card>
  <Card title="Comments" icon="comments">
    Add threaded comments to any ticket. Authors can edit or delete their own messages.
  </Card>
  <Card title="Analytics Dashboard" icon="chart-bar">

## Getting Started

<Steps>
  <Step title="Clone the repository">
    Clone the project and open the solution in Visual Studio or VS Code with the C# Dev Kit.
  </Step>
  <Step title="Create a Supabase project">
    Sign up at [supabase.com](https://supabase.com), create a new project, and collect your project URL and anon key.
  </Step>
  <Step title="Configure connection strings">
    Add your Supabase credentials to `appsettings.Development.json` and set the `DefaultConnection` string for EF Core.
  </Step>
  <Step title="Run the application">
    Run `dotnet run` from the project directory, navigate to the login page, and register your first account.
  </Step>
</Steps>

<Note>
  The first registered user becomes a regular **EMPLEADO**. A **SUPERUSUARIO** must manually elevate another user to the SOPORTE or SUPERUSUARIO role from the Admin panel before technician features become available.
</Note>
